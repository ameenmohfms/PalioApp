# Agent prompts

Populated from Phase 1 onward. Every agent prompt is composed as:

    _base.md  (product identity + Hard Rules §4 + language style)
  + {agent}.md kernel  (non-negotiable charter lines from spec §5)

Prompts are versioned assets: changes here are code changes — they go through review and
must keep the §13 eval suite green. The Safety Sentinel prompts have veto power over every
other agent's output; nothing in this directory may weaken them (Working Agreement 4).
